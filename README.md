This repository is for coding and other work relating to a class taken at JCU MB5370 Techniques in Marine Science 1

Module 1
Programming Fundamentals introduced the foundations of scientific programming and reproducible data analysis for marine science. Across four workshops, I developed practical skills in R and RStudio, including working with data structures, creating visualisations with ggplot2, organising reproducible projects, using Git and GitHub for version control, and applying automation, custom functions and AI-assisted coding tools. These skills provide a foundation for managing, analysing and communicating complex marine datasets in a transparent and reproducible way.
